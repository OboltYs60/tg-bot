Telegram бот для анализа Steam профилей, игр и их стоимости.

Возможности:

Мой профиль — информация о Steam аккаунте (ник, дата создания, статус онлайн)
Мои игры — список всех игр с количеством часов (пагинация по 10 игр, кнопки Назад/Вперёд)
Стоимость — примерная стоимость всех игр по текущим ценам Steam
Бесплатные игры — актуальные раздачи в Epic Games (обновляется вручную)
Популярное — топ игр по онлайну в Steam (реальные данные)

Установка:

pip install python-telegram-bot==20.7 requests==2.31.0 feedparser==6.0.10
python bot.py

Настройка:

1. Получи токен у @BotFather в Telegram
2. В файле TG BOT замени TOKEN на свой токен:
TOKEN = "ТОКЕН"

Технологии:

Python 3.10+
python-telegram-bot
Steam Web API
Feedparser
